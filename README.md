# NumeroTalk — Vedic Numerology Intelligence

Pure Vedic Principles · Ancient Wisdom · Modern Guidance.

NumeroTalk is a modern, modular Vedic numerology intelligence platform built with Next.js 16, React 19, and TypeScript.

## Features
- **Authentic Indian Vedic 3x3 Grid**: Standard layout `3 1 9 / 6 7 5 / 2 8 4`.
- **Vedic Grid Yogas**: Real-time evaluation of all 8 Vedic horizontal, vertical, and diagonal planes.
- **Name Number (Namank)**: Vedic phonetic vibration calculation with live Devanagari transliteration.
- **Vastu Numerology**: Directional alignments and spatial balance driven by `/mocks/rules/vastu-directions.json`.
- **Mahadasha & Antardasha**: Multi-tiered timeline forecast with yearly Vedic grids.
- **Marital Compatibility**: 5-pillar Vedic match making engine.
- **Bilingual Interface**: Full English and Hindi (`hi`) localized routes.

# Install dependencies
